# vuk6449's EFI Application Compiler Boy

Welcome to my EFI Application Compiler Boy!
Make sure that x86_64-w64_mingw32-gcc is installed on your linux distribution! It should be automaticly installed.
Usage: ./Make.sh filename.c
It will automaticly output a BOOTX64.EFI EFI application compiled from your C file, unless there are any errors
It WILL be rude if you mess up something, so please do not send hate. This is just for entertainment purposes only, as its as easy as typing in a command line, rather than using a shell, but I wanted it to be automated and easy-to-use, so you dont have to type that command over and over again.
